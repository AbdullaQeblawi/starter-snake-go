Add a new strategic feature to the BattleSnake AI:

1. Read the project-context.md to understand the architecture
2. Read main.go to see the current implementation
3. Ask the user what feature they want to add:
   - A* pathfinding
   - Voronoi space analysis
   - Opening book strategies
   - Multi-step lookahead
   - Custom algorithm
4. Design the feature:
   - Create helper function signature
   - Determine where to integrate it
   - Calculate impact on scoring system
5. Implement the feature incrementally:
   - Write helper functions first
   - Integrate into move decision logic
   - Add appropriate scoring/weighting
6. Test the feature with /test-snake
7. Commit changes with detailed description
