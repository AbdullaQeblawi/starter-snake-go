Analyze BattleSnake performance from server logs or test results:

1. Check the most recent server output or ask user to provide game results
2. Look for patterns in the logs:
   - Health management (when did we eat food?)
   - Move decisions (aggressive vs defensive)
   - Death causes (collision, starvation, self-trap)
   - Survival time trends
3. Calculate key metrics:
   - Average survival time
   - Food efficiency (food eaten per turn)
   - Aggression success rate
   - Space control effectiveness
4. Identify weaknesses:
   - Repeated mistakes
   - Strategic failures
   - Algorithm inefficiencies
5. Suggest specific improvements based on data
6. Recommend which scoring parameters to adjust
